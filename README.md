## 📖 What's inside / Contenu

One PDF in three parts, each with its own page numbering and back cover — you can split it:
1. **Book / Livre** — radio basics, bands, modes, listening, DIY (antennas, radios, cables), regulations.
2. **UV-K1 / UV-K5 V3 annex / Annexe** — firmwares, multiboot, Fusion, overlay apps.
3. **Manuals annex / Annexe Manuels** — original firmware manuals, translated.
